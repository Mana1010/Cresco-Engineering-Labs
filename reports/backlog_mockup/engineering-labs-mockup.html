This isn't one of the official Engineering Labs menus. #09 is an API endpoint (/api/v1/health) that returns JSON for monitoring tools such as UptimeRobot or Jerome's DevOps checks. Staff never see it. This page only shows what it returns, and what an optional status page built on it could look like.

      
Service health #09 Health Endpoint

      
Reports application uptime, database connectivity and Redis queue status.

Monitoring tools mainly read the HTTP status code: 200 means healthy, 503 means a problem, so send an alert. The endpoint usually needs no login (allow_guest), so it should expose no secrets or detailed internals. The exact fields aren't defined in the backlog; this shape is a suggestion.
